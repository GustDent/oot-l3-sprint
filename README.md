# Link — L3 Sprint

Hold the left stick button (L3) while moving on foot to sprint at **2× the original ground speed** in *Ocarina of Time* 1.1.1 on Lichii. Release L3 while moving to return to **1.15×**. The stick click works as a hold, so you can slow down before a ledge without pressing it again.

[Download Link — L3 Sprint v3.0.0 (ZIP)](./Link-L3-Sprint-v3.0.0.zip?raw=true)

## Installation

1. Check your game version against the build below. In Lichii, open the game's mod directory from its context menu.
2. Install and enable [Manual Shield v0.1.5 by REXCRAFT88](https://github.com/REXCRAFT88/OOT-Mods-by-rexcraft88/releases/tag/manual-shield-v0.1.5). L3 Sprint reads the stick button through that mod.
3. Extract the folder named `Link - L3 Sprint` from the download directly into the game's mod directory, alongside Manual Shield. If you already have v2, replace the files in the existing folder.
4. Enable both mods in the game's add-ons, save your progress, and restart the game.

## Controls

| Action | Input |
| --- | --- |
| Move at 1.15× ground speed | Tilt the left stick |
| Sprint at 2× ground speed | Hold L3 while moving |
| Target | L, with the default Manual Shield layout |
| Block | ZL, with the default Manual Shield layout |

Young Link stays upright when targeting with the Hylian Shield and crouches behind it when you block. If L3 has no effect, check that your controller's left stick click is mapped to the Switch left stick button and that Manual Shield v0.1.5 is enabled.
